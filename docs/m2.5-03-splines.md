# M2.5-03 shape splines

**Status:** landed 2026-11-01. The continentalness/erosion tables and the
height evaluator are frozen.

## Acceptance

| Requirement | Result |
|---|---|
| Continentalness spline table | 10 knots, `-1..1` → 0–10,800 m |
| Erosion spline table | 5 knots, `0..1` → 1,200–0 m relief |
| Height spline | `base(c) + relief(e) * weight(c)`, clamped to 0–12,000 m |
| Sea level 6,600 m | exactly the `c = 0` knot and every coast height |
| Splines monotonic where required | base/weight non-decreasing, relief non-increasing, surface monotone in both inputs |
| Height clamped | evaluator clamps to `[FLOOR, PEAK]`; tests cover a 129 × 65 grid |
| Unit table tests | 14 integration tests plus 2 unit tests and a doctest |

Verify with `cargo test -p voxel-worldgen splines`.

## Tables

All values are Q16.16 metres; `ONE` is 1.0. The tables are `const`, so the PCHIP
slopes are derived at compile time.

### Continentalness → base elevation

| Continentalness | Elevation | Reads as |
|---:|---:|---|
| -1.000 | 0 m | trench floor |
| -0.750 | 1,800 m | trench |
| -0.500 | 4,200 m | deep ocean |
| -0.250 | 6,450 m | shelf edge (150 m below sea) |
| 0.000 | 6,600 m | coastline |
| 0.125 | 6,750 m | beach and lowland |
| 0.250 | 7,000 m | plains |
| 0.500 | 8,000 m | hills |
| 0.750 | 9,400 m | mountains |
| 1.000 | 10,800 m | high mountains, before relief |

This matches the design's ocean bands: shelf 0–200 m below sea level, deep
200–4,000 m, trench 4,000–6,600 m.

### Erosion → relief amplitude

| Erosion | Relief | Reads as |
|---:|---:|---|
| 0.000 | 1,200 m | least eroded, full relief |
| 0.250 | 900 m | |
| 0.500 | 500 m | |
| 0.750 | 200 m | |
| 1.000 | 0 m | most eroded, rounded |

The erosion channel is `0..1` with `0 = least eroded`, matching the macro tile
convention (`u8` 0–255, 0 least). Noise is signed; M2.5-05 maps it to the
channel range before sampling this table.

### Continentalness → relief weight

| Continentalness | Weight |
|---:|---:|
| -1.000 | 0 |
| -0.250 | 0 |
| 0.000 | 0 |
| 0.125 | 0.5 |
| 0.250 | 1.0 |
| 1.000 | 1.0 |

The sea floor and the coast carry no relief, so **a coast is exactly sea level**
for every erosion value and the ocean is unaffected by erosion. Relief fades in
over the first quarter of the land, which gives a flat beach without a separate
beach rule (M2.5-12 can still add a beach material band).

### Resulting profile

| Continentalness | e = 0 | e = 0.5 | e = 1 |
|---:|---:|---:|---:|
| -1.000 | 0 | 0 | 0 |
| -0.500 | 4,200 | 4,200 | 4,200 |
| 0.000 | 6,600 | 6,600 | 6,600 |
| 0.125 | 7,350 | 7,000 | 6,750 |
| 0.250 | 8,200 | 7,500 | 7,000 |
| 0.500 | 9,200 | 8,500 | 8,000 |
| 0.750 | 10,600 | 9,900 | 9,400 |
| 1.000 | **12,000** | 11,300 | 10,800 |

Peak 12,000 m is reachable only at continentalness 1 with zero erosion; that is
the design's "peaks 12,000 m / land relief 5,400 m above sea".

## Interpolation

Each segment is a cubic Hermite with **PCHIP** slopes:

- interior slope = harmonic mean of the two adjacent secants when they agree
  in sign, otherwise zero;
- endpoint slope = the adjacent secant.

This is the Fritsch–Carlson construction. A monotone table therefore stays
monotone inside every segment and cannot overshoot between control points — a
plain Catmull–Rom or natural cubic would dip below the shelf or above the peak
between knots. It is also `C1` across knots, so a biome blend does not crease.

Everything is integer: the secant `dy << 16 / dx`, the harmonic mean in `i64`,
the Hermite basis in Q16.16 and the final `i64` accumulation. There is no
`libm`, no float and no platform-dependent rounding, so the tables are
bit-exact and can be evaluated in a `const` initializer.

Outside the domain the endpoint value is returned; inputs are clamped by the
table itself, so a caller cannot walk off the end.

## Blending rule

The evaluator takes **already blended** continentalness and erosion. The design
requires shape blending before evaluation (§5.2): blending two finished heights
draws a straight line through a ridge. M2.5-10 computes the biome weights, then
blends the shape parameters with those weights, then calls
`surface_height(continentalness, erosion)` once.

Monotonicity makes the blend safe in both directions:

- `base` and `weight` non-decreasing, `relief >= 0` → height non-decreasing in
  continentalness;
- `relief` non-increasing, `weight >= 0` → height non-increasing in erosion.

Both are asserted over the whole domain, not only at control points.

## Height channel

`macro_grid::height_from_q16` converts Q16.16 metres to the tile's 0.25 m unit,
rounding half up and clamping: sea level 6,600 m → **26,400 units**, peak
12,000 m → **48,000 units**, and anything negative → 0. M2.5-05 writes the
height plane through this function.

|---|---:|---:|
| `surface_height(c, e)` | 74.2 M/s | 13.5 ns |
