# M2.5-18 landmark anchors

**Status:** landed 2026-11-02. `crate::landmarks` puts one terrain-fitted
landmark in every 32 km cell and the `map --landmarks` command prints the
distribution.

## Acceptance

| Requirement | Result |
|---|---|
| One landmark per cell | a 32 × 32 grid, exactly 1,024 cells and 1,024 unique anchors |
| 20–50 km spacing | a 32 km cell with a ±4 km anchor jitter gives 24–40 km between neighbours |
| Five types | massif, canyon/falls, volcano, giant grove, monolith/arch; all five appear for seeds 1–5 |
| Type fits terrain | classification uses the dominant biome, erosion, slope and temperature; every cell is checked against its rule |
| Map dump shows distribution | `map --landmarks` prints the 32 × 32 letter grid, per-type counts and one sample anchor |
| Tests | `cargo test -p voxel-worldgen landmarks` (6 unit) + the two `cli_map` tests |

Verify with `cargo run -p voxel-worldgen -- map --landmarks`.

## Grid and anchors

The design asks for a jittered 20–50 km grid. The world is 1,024 km square, so
a fixed **32 km cell** divides it exactly into 32 × 32 cells. The anchor is
jittered by up to **±4 km** around the cell centre:

```text
anchor = cell_centre + hash2(seed, cell_x, cell_z) mapped to [-4 km, +4 km]
```

Adjacent anchors are therefore 24–40 km apart, inside the design band, and the
grid remains directly indexable: “which landmark is near this chunk?” is a cell
lookup, not a search. Every anchor stays inside its own cell, so the grid has
no overlaps or gaps.

## Five types

| Type | Rule |
|---|---|
| massif | a cold (`< 0.39` channel) mountain, alpine or hills biome |
| canyon/falls | any land with slope `≥ 0.12` or erosion `≥ 0.65` |
| volcano | a warm (`≥ 0.39`) mountain, alpine or hills biome |
| giant grove | forest, taiga, swamp or plains |
| monolith/arch | ocean (sea stack or sea arch), or a dry/cold lowland |

The canyon rule runs before the biome split, so an eroded desert or a steep
savanna can be a canyon; the ocean rule runs first, so no underwater landmark
is a massif or grove. Rule order is deterministic and documented in
`classify`.

## Classification

`LandmarkSample` carries the anchor's surface, continentalness, erosion,
temperature, humidity and a local slope. The slope is the larger of the east–
west and north–south height differences over a 512 m baseline, expressed as
Q16.16 rise over run:

```text
slope = max(|h(x+512) − h(x−512)|, |h(z+512) − h(z−512)|) / 512
```

The dominant biome comes from the same M2.5-10 softmax the surface rules use,
so the landmark type and the terrain content cannot drift apart. The oak
grove type will therefore prefer a forest or plains cell, and a hot mountain
cell becomes a volcano rather than a massif.

## Tests

Unit (`src/landmarks.rs`):

- one unique anchor per cell, 1,024 in total;
- every anchor is inside its own 32 km cell;
- adjacent anchors stay in the 20–50 km band;
- the grid is deterministic and seed-sensitive;
- all five types appear for seeds 1–5;
- every landmark matches its terrain rule (ocean/type, canyon threshold,
  mountain temperature, grove biome).

CLI (`tests/cli.rs`):

- `map --landmarks` prints a 32 × 32 letter map with all five letters and the
  per-type counts;
- `map` without `--landmarks` is rejected.
