Optimization path

Top: p95 edit cost. Bottom: the same number as a share of the full pass, with the 20% task line. The jump from 17.3% to 5.7% is the neighbour mask replacing per-cell coordinate division and bounds checks.

The four changes

  1. Increase-only fast path — skip the dirty-region reseed when no edit removes light. 51.8 → 11.5 µs p95 (127.8% → 31.6%).
  2. Channel-selective propagation — an emitter edit no longer runs the sky pass, and a pure gain seeds only the edited cell. → 9.9 µs (28.1%).
  3. Scratch reuse — buckets and seed lists live on the state; capacity-preserving clone_from. → 7.6 µs (17.3%).
  4. Neighbour mask — one byte per cell with six direction bits and constant index offsets; no division or bounds checks in the inner loop. → 2.06 µs (5.7%).

Correctness
