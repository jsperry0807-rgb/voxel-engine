# M2.5-07 river extraction

**Status:** landed 2026-11-01. The hydrology forest is now a vector river
network with width, depth, Strahler order and delta flags.

## Acceptance

| Requirement | Result |
|---|---|
| Vector polylines with width/depth/order | `RiverNetwork::extract`, segments of `RiverPoint` |
| Width from catchment, 10–200 m | monotone accumulation table, clamped to `[10, 200]` |
| Every river reaches sea or a lake | terminal segments end at `Mouth::Sea` or `Mouth::Lake`; confluence links continue and terminate |
| No uphill segments | filled elevation is non-increasing along every segment |
| Deltas | sea mouths with order ≥ 2 and a mouth gradient ≤ 2 mm/m |
| Verify | `cargo test -p voxel-worldgen rivers` (10 tests) |

## Model

### Segments

A cell is a river when its flow accumulation is at least
`DEFAULT_THRESHOLD = 512` and it is not a lake deep enough to end a river
(`MIN_TERMINAL_LAKE_DEPTH = 4` units, one metre). Extraction splits the flow
forest into **segments**:

- a segment starts at a headwater (no river child) or at a confluence;
- it runs downstream to the next confluence, the sea, a map edge or a
  terminal lake;
- a confluence is both the last point of every upstream segment and the first
  point of the downstream segment, so the network is a DAG and the trunk is
  stored once.

Every river cell belongs to at least one segment.

### Width and depth

Both are monotone tables over accumulation:

| Accumulation | Width | Depth |
|---:|---:|---:|
| 512 | 10 m | 0.4 m |
| 4,096 | 20 m | 0.9 m |
| 32,768 | 45 m | 2.0 m |
| 262,144 | 90 m | 4.5 m |
| 2,097,152 | 180 m | 9.0 m |
| 5,000,000 | 200 m | 9.0 m |

Width is clamped to the design's 10–200 m. Depth is not clamped; the table
ends at 9 m for the largest channels. Values are Q16.16 metres, like every
other length in worldgen.

### Strahler order

River cells are visited in **ascending accumulation**, which is a topological
order because a parent's accumulation is strictly larger than any child's. A
cell with two or more children of its maximum order gains one; otherwise it
keeps the maximum child order. Terminal segments carry the order of their
mouth; confluence segments the order of the junction.

### Mouths

| Mouth | Meaning |
|---|---|
| `Sea` | the outlet is at or below sea level |
| `Lake` | the next cell is a lake at least one metre deep |
| `MapEdge` | a border outlet above sea level (rare: the world has an ocean rim) |
| `Confluence` | the segment continues downstream from its last point |

Shallow single-cell puddles from the valley detail do **not** end a river; they
stay part of the channel, which avoids chopping the network into thousands of
one-cell fragments.

### Deltas

A sea mouth is a delta when the river has Strahler order ≥ 2 (it carries a
confluence) and the last eight points drop at most 2 mm/m — the design's
"deltas where order and gradient drop". The predicate is public as
`is_delta(order, gradient)` and the flag is re-checked against the gradient in
the tests.

```sh
cargo run -p voxel-worldgen --release -- rivers --seed 1
```

The zero edge count is the ocean rim doing its job: every border outlet is sea,
so a river that leaves the frame has already reached the sea. The 21,281 lake
mouths reflect the 4.3% lake-cell share; M2.5-08 extracts lakes and can merge
or filter those endings.

## Tests

- Hand-checked plane: one row, accumulation 5→2, four points, order 1, sea
  mouth, minimum width.
- Lake fixture: a 5.25 m pit between the source and the sea produces a
  `Mouth::Lake` segment and a separate outflow segment that reaches the sea.
- Random fields (six seeds): every segment is 8-connected, accumulation grows
  downstream, filled elevation never rises, width stays in range, confluence
  junctions are shared with the downstream segment, and following confluence
  links always terminates.
- Determinism: two extractions produce identical segments and hashes.
- Width monotonicity with accumulation.
- Delta predicate boundaries and a check that every delta flag matches the
  gradient rule.
- Empty network on a fully flooded plateau.
