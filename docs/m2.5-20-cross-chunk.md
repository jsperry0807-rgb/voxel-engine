# M2.5-20 cross-chunk feature determinism

**Status:** landed 2026-11-02. The harness cuts 1,000 real structure stamps and
1,000 tree fixtures at a chunk border, generates each side independently through
a with-margin window, and compares the shared overlap block for block.

## Acceptance

| Requirement | Result |
|---|---|
| Two adjacent chunks agree | both sides build a half-open block window with a 2-block apron; the 4-block shared overlap is byte-equal |
| A feature crossing the border is complete from both sides | every sampled structure and tree has at least one block in the overlap |
| Anchors outside the chunk are found | a window east of a tower contains no anchor, but the margin query still finds the east wall |
| 1,000 sampled features | 1,000 structures from the real `StructureGrid` and 1,000 deterministic tree fixtures |
| Tests | `cargo test -p voxel-worldgen cross_chunk` — 4 integration tests |

## Window model

Chunks are 8 blocks on a side (8 m at the 1 m block scale). A window is
half-open `[min, max)` and has a **2-block apron** on each side:

```text
left  = [border − 10, border + 2)
right = [border − 2,  border + 10)
shared overlap = [border − 2, border + 2)
```

Every feature is generated from its own anchor and world height, not from the
chunk that happens to ask. The two windows are built independently; if the
shared cells differ, the test fails with the first missing or unequal block.

## Structures

`structures_in_window` asks the `StructureGrid` for every structure cell within
a 64 m margin of the window, stamps each prefab with the same height function,
and keeps the blocks inside the window. The margin is what lets a chunk on one
side find a prefab anchored just outside it.

For each of the first 1,000 structures:

- the border is the anchor's `x`;
- the left/right windows span the structure's `z` extent and 64 m around its
  surface;
- the shared overlap must be non-empty and equal on both sides.

The separate anchor-outside test takes a window on the east side of a tower
(`anchor.x + 1` onward), so the anchor is outside the window while the east
wall is inside. The margin query must still return the wall.

## Trees

Flora proper lands in M2.5-21, so this suite carries a deterministic **tree
fixture**: an oak trunk five blocks tall with a small leaf canopy, using
`voxel:oak_log` and `voxel:oak_leaves`.

1,000 trees sit on a 100 × 10 grid at 20 m spacing. Each tree is cut at
`x = tree.x`; both windows query the tree list by bounding box, build the blocks
independently, and compare the shared cells. This is the same failure mode as a
real tree: the canopy crosses the border while the trunk anchor is on one side.

## Why this is a harness, not a new generator

The fields and prefabs already take a seed, an anchor and absolute world
coordinates. The only cross-chunk bug left is **discovery**: a chunk must ask
for features whose anchor is not inside it. The test makes that query explicit
with a margin and proves that the blocks are identical from both sides.

## Tests

`tests/cross_chunk.rs`:

- 1,000 structures, both sides, non-empty shared overlap and byte-equal keys;
- 1,000 trees, both sides, byte-equal keys;
- a structure window with its anchor outside still finds the east wall;
- the half-open overlap geometry itself (`[8, 12)` for a border at 10).

## Files

- `crates/engine/worldgen/tests/cross_chunk.rs` — windows, margin queries and
  the two feature sets

No production module changes: the harness uses the committed `StructureGrid`,
`Structure::stamp`, `PlacedBlock` and the M2.5-31 structure keys.
